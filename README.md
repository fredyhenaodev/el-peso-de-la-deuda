# El peso de la deuda

Simulador para el taller de finanzas de la reunión de hombres de MCI Rionegro (2 Reyes 4:1-7).

Muestra cuánto tiempo e intereses se ahorran al subir la cuota de un crédito, y genera una carta para pedirle al banco el aumento de cuota con abono a capital y reducción de plazo.
